# claude-ceshi

> 用来测试 Claude Code 自定义 skill 的仓库。目前收录一个中文恋爱军师 skill：**狗头军师（进攻版）**。

## 项目简介

`claude-ceshi` 是一个 Claude Code 的试验仓库，用来验证项目级 skill 能不能直接部署、自动加载和调用。

仓库里的主角是**狗头军师（进攻版）**。它改编自开源项目 [goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi)：原版是覆盖恋爱全过程的关系顾问，进攻版把重点收窄到"追求期怎么往前推"，提供进攻时间表、档位切换、主导式话术和线下见面安排，帮你把"不敢约、聊不热、停在线上"变成具体的下一步。

**亮点**

- **开箱即用**：只有一个 `SKILL.md`，没有外部依赖。克隆仓库、启动 Claude Code 就能用。
- **给能直接发的话**：问"这句怎么回"，直接给一条可复制的回复，再补一条稳健备选、发送时机和后续怎么接。
- **节奏清楚**：每次分析都告诉你现在进行到哪一步、有没有落后、下一步做什么。
- **强度可调**：稳健、进攻、满攻三个档位，随时说"再猛一点"或"收一点"。
- **有底线**：对方明确拒绝、让你别联系或拉黑时，立即停止。

## 快速开始

```bash
git clone https://github.com/a16689525392-prog/claude-ceshi.git
cd claude-ceshi
claude
```

进入 Claude Code 后，直接描述你的情况（比如"她说最近忙，下次吧，我怎么回？"），skill 会自动触发；也可以输入 `/goutoujunshi` 手动调用。

## Skills

### 狗头军师（进攻版）

路径：`.claude/skills/goutoujunshi/SKILL.md`

一个恋爱军师 skill，专门帮你在追求阶段往前推进。它会分析聊天记录或截图、判断信号冷热、找出卡在哪一步，然后按进攻时间表给出可以直接发送的话术和推进方案。

**适用场景**：喜欢上一个人、暧昧、“这句怎么回”、邀约、约会、表白、确认关系、对方冷淡、在几个人之间做选择、分手后想复合。

**核心机制**

| 模块 | 作用 |
| --- | --- |
| 进攻时间表 | 拿到联系方式 24 小时内发第一条，3–5 个来回内提邀约，认识 2–4 周内表白或问关系定位 |
| 三个档位 | 稳健／进攻（默认）／满攻，按信号温度切换；随时可以说“再猛一点”或“收一点” |
| 卡点诊断 | 展示面、对话、情绪、邀约、互惠、现实障碍，找出卡在哪一层再对症出手 |
| 信号温度 | 热、温、冷三档，只看持续行为，不凭一句话或一个表情下结论 |
| 话术编排 | 七种主策略，每轮只选一个；配合主导式语言、6 级调情升级梯和场景话术骨架库 |
| 线下带领 | 第一、二、三次见面各自的安排、转场、牵手和表白时机 |
| 宽松止损 | 只要对方没有明确拒绝就不轻易撤；明确拒绝、让你别联系或拉黑时立即停止 |
| 演练模式 | 说“陪我练”，由 Claude 扮演对方，每轮点评并给出替代说法 |

**输出示例（“这句怎么回”）**

```text
【直接发 · 进攻／满攻】一条可复制成品
【稳健备选】一条
【时机】什么时候发
【后续】对方积极 / 含糊 / 不回 时分别怎么做
```

**使用方式**

- Claude Code：在本仓库目录中启动 Claude Code，`.claude/skills/` 下的 skill 会自动加载；也可以输入 `/goutoujunshi` 直接调用。
- 其他项目：把 `.claude/skills/goutoujunshi/` 整个文件夹复制到目标项目的 `.claude/skills/` 下，或复制到 `~/.claude/skills/` 作为个人 skill。
- Claude 应用：把 `goutoujunshi` 文件夹打包成 zip，在应用设置的 Skills 页面上传。

### 与原版对比

| 维度 | 原版 | 进攻版（本仓库） |
| --- | --- | --- |
| 定位 | 全周期关系顾问：追求、冲突、分手、婚姻家庭 | 追求期推进教练：暧昧 → 确认关系 |
| 目标 | 用户综合利益，“得到某个人不是唯一胜利” | 尽快拿到结果，“维持现状就是后退” |
| 节奏 | 看反馈给观察窗口，没有固定时间表 | 进攻时间表，2–4 周内要一个结果 |
| 默认档位 | 稳健／会撩／强势，由用户选择 | 默认“进攻”，信号热直接“满攻” |
| 止损 | 结合投入失衡判断，及时降级或退出 | 宽松：邀约 5 次没成、重启 3 次没回应、2 个月对方从没主动，才降温 |
| 多人 | 分别分析再比较 | 主动建议确定关系前多线并行 |
| 结构 | 精简的 SKILL.md + 46 份按需加载的参考文档 + 脚本 | 单个 SKILL.md，话术和清单全部内置，零依赖 |
| 长期记忆 / ChatLab | 支持（需用户同意） | 不支持 |
| 安全与反操控边界 | 有专门章节 | 大幅精简，只保留“明确拒绝就停”等底线 |

**怎么选**：想追、卡在不敢约或聊不出火花，用进攻版；遇到冲突、投入失衡、分手婚姻问题，或有安全顾虑，用原版。

完整对比（新增内容、删减内容和使用注意）见 [COMPARISON.md](./COMPARISON.md)。
